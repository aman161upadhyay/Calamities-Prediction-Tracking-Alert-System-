# Dashboard and CRM checks

- [ ] The user's next decision determines the first view.
- [ ] Schema, units, timezone, freshness and permissions are supplied.
- [ ] Tables precede secondary charts when records are the task.
- [ ] Density is measured with realistic rows and long names.
- [ ] Identifiers align left; numerical magnitudes align right.
- [ ] Row navigation differs from selection and contextual actions.
- [ ] Bulk scope and cross-page selection are explicit.
- [ ] Filters, sorting and useful view state survive back navigation.
- [ ] Empty, no matches, stale, partial, denied and failed-save paths work.
- [ ] Native table semantics remain unless a complete grid interaction is needed.
- [ ] Chart values have accessible alternatives.
- [ ] Narrow screens preserve the primary task.
- [ ] Saves reflect server confirmation; undo is truthful.
- [ ] No external email or data export occurs without approval.
