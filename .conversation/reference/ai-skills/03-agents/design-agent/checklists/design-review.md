# Design review

Record pass, fail or unverified with evidence for every applicable item.

## Hierarchy
- [ ] The first view exposes the primary job and action.
- [ ] Secondary and destructive actions have appropriate prominence.
- [ ] Navigation follows the user's conceptual model.
- [ ] Operational pages prioritize work over decorative KPIs.
- [ ] Each distinctive choice relates to the brief.

## Spacing and layout
- [ ] Named spacing tokens explain grouping.
- [ ] Within-group gaps differ from between-group gaps.
- [ ] Desktop, intermediate and narrow widths have intentional layouts.
- [ ] Media and fonts do not cause disruptive layout shift.
- [ ] Reflow preserves required content and controls.

## Type and colour
- [ ] Font license, fallback and loading behavior are known.
- [ ] Type roles, leading and reading measure fit actual content.
- [ ] Long names and localization fit.
- [ ] Semantic pairs pass measured contrast in each theme and state.
- [ ] Status does not depend on colour alone.

## States
- [ ] Hover where applicable, focus, selected and disabled states exist.
- [ ] Loading, empty, no-results, offline, permission and failure paths work.
- [ ] Save, delete, back, retry and undo behavior is explicit.
- [ ] Forms retain valid input after failure.
- [ ] Table selection and bulk scope are unambiguous.
- [ ] Every enabled action works.

## Motion
- [ ] Each transition explains a change.
- [ ] Frequent actions remain fast and interruptible.
- [ ] Reduced motion preserves information.
- [ ] Native scrolling and content access survive script failure.
- [ ] Runtime behavior has been measured on the target device.

## Accessibility
- [ ] `accessibility-floor.md` has evidence, including manual tests.
- [ ] Dialog focus moves and restores correctly.
- [ ] Labels, error associations and live status announcements are correct.

## Copy
- [ ] Heading and CTA name concrete outcomes.
- [ ] Vocabulary stays consistent.
- [ ] Errors and empty states give a useful next action.
- [ ] Pricing states actual terms.
- [ ] Proof is authorized and traceable.
