# Prioritize work over ornament

Use tables for comparison and record scanning. Keep names left aligned and numerical magnitudes right aligned. Use tabular figures where available. Define row-open separately from checkbox selection.

Filters need visible active state, reset behavior and preserved useful view state. Distinguish first-use empty from no matches. Define bulk scope across pages.

Detail panes should preserve context and have a tested focus lifecycle. On narrow screens reprioritize record facts and next action instead of shrinking a desktop sidebar.

Choose density through realistic content and visible-row needs. A 48px row is an example starting point, not a universal requirement. Keep essential values readable.

Show units, comparison period and freshness beside metrics. Preserve the last successful result after refresh failure with an explicit stale/error label. Charts need a decision and an accessible data alternative.

Study [Twenty](https://github.com/twentyhq/twenty) for record workflows. Root code is AGPL-3.0; linking is not permission to copy into a permissive package. Linear and Attio are product references with limited verification in this research.
