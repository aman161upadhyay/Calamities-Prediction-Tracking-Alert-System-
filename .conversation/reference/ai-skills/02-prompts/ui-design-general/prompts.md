# Constraint-led prompt patterns

Use these original, untested patterns after the design brief. Supply approved content, token files, stack/version, rights and state inventory. Pair each with `../../03-agents/design-agent/WORKFLOW.md`.

## Reference board

```text
For [surface/user/task], analyze the supplied three references.
Borrow [density] from reference A and [type hierarchy] from B.
Avoid [specific feature] from C. Do not copy protected assets or branding.
Return a choice-to-brief table, token plan and two layout sketches.
Identify assumptions and ask for missing material facts before building.
```

Example: a ceramics booking page can borrow photographic scale without copying an editorial reading order that hides dates.

## Constraint-first

```text
Design [task] within existing semantic tokens, installed components,
[viewport matrix] and [performance budget]. Prioritize [decision].
Cover supplied failure and permission states.
Explain any library addition before installation.
Compare the plan against an unrelated product and revise unsupported defaults.
```

## Typography-first

```text
Using our licensed family, define roles for title, body, label and operational
values. Test supplied long names, numeric columns and narrow widths before
effects. Propose leading and reading measure with screenshots.
Keep expression in display roles when operational numbers need more legibility.
```

## Density-first

```text
For [operator] making [decision], show [required visible records] at [viewport].
Choose necessary columns from supplied schema. Separate navigation and selection.
Compare compact and comfortable layouts with the same records.
Do not trade labels or target acquisition for row count without explicit approval.
```

## Operational mood

```text
Interpret “quiet” as low chroma, limited elevation and little motion.
Interpret “editorial” as purposeful reading hierarchy, asymmetric grid and
approved photography. Use either only if it serves this brief.
Translate our chosen mood [word] into palette, type, density and behavior.
If “premium” or “modern” is the only direction, ask a concrete clarification.
```

Acceptance: choices map to task facts and pass states/accessibility checks. Failure modes: mood-only gradients, a reference collage and novelty that breaks conventions.
