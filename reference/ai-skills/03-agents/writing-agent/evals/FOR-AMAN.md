# Run writing evaluations

Ask: "Run the candidate prompt on these inputs without exposing gold criteria. Save anonymized outputs for my review." Supply sanitized test briefs and a fixed model configuration.

Grant access only to the test inputs and selected training examples. Refuse raw inbox access, held-out original retrieval, and sending. Compare the candidates before seeing their labels.

Mark factual failures before choosing a preferred voice. Explain one wording change for each rejected draft. Rerun after changing the profile, model, or retrieval method. Approve a release only after the larger per-register test set meets your gates.
