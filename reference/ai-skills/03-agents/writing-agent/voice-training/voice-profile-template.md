# Voice profile template

Create one private Markdown profile per register. The fields below are a collection form, not a claim about Aman's habits. Omit unmeasured values and record the reason. Do not populate fields with guessed defaults.

| Field | Evidence to record |
|---|---|
| Identity and version | Owner, register, revision date, approval date, permitted audience. |
| Context | Channel, recipient relationship, power difference, reader familiarity. |
| Languages | Observed languages and approved conditions for code-switching. |
| Sample provenance | Approved IDs, excluded IDs with reasons, count, date range, confidence. |
| Sentence shape | Word-count p10, median, p90; fractions below 8 and above 25 words; fragment use. |
| Paragraphs | Median sentence count, uses of one-line paragraphs, context exceptions. |
| Openings | Exact redacted examples with IDs and contexts. |
| Greetings and signoffs | Separate friends, colleagues, cold email, and Slack; when omitted. |
| Punctuation | Contractions, parentheses, semicolons, dash types per 1,000 words, exclamation rates. |
| Orthography | Capitalization, spelling variants, emoji position where permitted. |
| Humor | Supported kind, examples, recipients or subjects to avoid. |
| Directness | Requests, disagreement, apologies, uncertainty, each with examples. |
| Vocabulary | Normal technical terms, plain words, recurring phrases with context. |
| Structures | Quick replies, asks, corrections, disagreement, articles. |
| Negative list | Aman-rejected phrases, preferred replacements, scope of each prohibition. |
| Counterexamples | Technically correct but unlike Aman; too formal; context-specific exceptions. |
| Personal claims | Separate task-authorized experience IDs; never inferred from style. |
| Boundaries | Recipient privacy, disclosure, no invented memories or commitments. |
| Open issues | Unmeasured fields and questions for Aman. |

For each preference record its status: observed, explicitly approved, or uncertain. Attach sample IDs and counterexamples. A single example supports a hypothesis, not a universal rule. Segment URLs, code, abbreviations, and chat fragments consistently before measuring sentence lengths.
