# Draft work messages

Ask: "Write a Slack status update. Separate completed work from the blocker. The next update is authorized for 16:00 UTC; no delivery date is approved."

Supply the channel, audience, current facts, owner, deadline with timezone, and permitted promises. For PRs, supply the actual diff and test evidence. Train email and Slack separately with your approved messages.

Grant read access to the selected brief and sanitized examples. Refuse broad workspace searches, customer data, and send permissions. Check that the draft does not repeat context the recipient already has.

Run the email and PR evals before use. Review owners, dates, test results, and degree of certainty first. Then correct the tone. Save approved wording as a new example only after removing private facts.
