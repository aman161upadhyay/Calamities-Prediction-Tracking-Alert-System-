# Slop pass

- [ ] The first sentence carries the claim or needed action.
- [ ] Every importance claim has a supported consequence.
- [ ] No staged question, empty contrast, or repeated closer remains.
- [ ] Every list item adds distinct information.
- [ ] Formatting fits the channel.
- [ ] Helpful relativizers remain; noun relationships are clear.
- [ ] Subject and verb are close enough to follow.
- [ ] Unusual noun-derived verbs and human actions assigned to objects are reviewed.
- [ ] Code and quotations remain intact.
- [ ] Legitimate warning matches have an exception reason.
- [ ] The draft passes claim preservation after editing.
