# Draft a personal reply

Ask: "Draft a short reply to a close friend. I want to decline this invitation without proposing another date. Use my approved personal examples. Do not invent a reason."

Supply the incoming message, relationship, desired boundary, and any feeling you want expressed. Select redacted examples from similar relationships. Grant access only to those examples. Refuse contact searches and send access.

Review warmth and commitments before wording. The agent must not manufacture affection, an apology, a shared memory, or availability. Run the personal blind comparison and claim-preservation evals. Tell the agent which exact phrase you would replace, then approve the revised draft yourself.
