# Pattern reference

| IDs | Inspect | Safe response |
|---|---|---|
| L01-L20 | Abstract filler, sales verbs, empty transitions | State the supported action or cut the filler. |
| S01-S12 | Hidden actors, noun stacks, long dependencies, odd word combinations | Restore relationships without inventing actors. |
| ST01-ST08 | Preambles, repeated summaries, empty outlines | Move the decision forward and remove redundancy. |
| R01-R10 | Staged questions, empty contrasts, invented opposition | Keep meaningful distinctions; cut theater. |
| F01-F08 | Unnecessary headings, labels, wrappers | Match the medium. |
| T01-T08 | False enthusiasm, intimacy, or neutrality | Use only authorized stance and feelings. |
| E01-E08 | Ceremony, buried asks, promises | Make the ask explicit; preserve authority limits. |
| LI01-LI08 | Manufactured confession and social proof | Use supplied observations only. |
| A01-A10 | Invented hooks, source theater, overclaims | Map each claim to evidence. |
| C01-C10 | Invented rationale, tests, concurrency, scope | Verify against implementation and test evidence. |
