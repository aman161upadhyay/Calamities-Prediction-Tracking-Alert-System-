The October Wikipedia snapshot places em dash overuse among historical indicators dated 2022 to September 2026. Provider changes and public criticism can change phrase frequencies. Genre also changes the meaning of a cue: Markdown is normal in a PR but can be residue inside wikitext.

For each maintained rule record ID, source date, genre, observed model version when known, approved exceptions, and false positives. Unknown model versions remain unknown. Review after model changes and on a quarterly schedule as a local maintenance policy. Keep a rule only if it improves held-out drafts without factual or voice regressions.

The catalogue uses new exercise examples from the research dossier, not copied Wikipedia article passages. The [Wikipedia adaptation](../../../06-reference-library/articles/wikipedia-signs-of-ai-writing-cc-by-sa/wikipedia-signs-of-ai-writing.md) has its own attribution and share-alike notice.
