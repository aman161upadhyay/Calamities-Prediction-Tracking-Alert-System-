# Run a slop pass

Ask: "Edit this draft with claim preservation. Report catalogue IDs for substantive edits. Ask before adding detail. Keep code and quotations unchanged."

Supply the draft, factual brief, channel, and approved voice profile. Grant read access to those inputs only. Refuse account access, automatic replacements, and detector-evasion work.

Review the proposed edits against the claim ledger. If a concrete detail is missing, supply it or accept a less specific sentence. Do not reward a smoother sentence that changes your promise.

Run the slop-score and claim-preservation evals. For dense text, run the Clark-style case too. Approve legitimate phrase exceptions explicitly. Use your corrections to update the rule's context, not to declare that a word proves AI authorship.
