# Select skills

Tell your agent the task, stack, risk and budget. Ask it to select one matching skill before loading its body. For a behavior change, use the vendored TDD skill and verification gate. Add debugging only when evidence shows a failure.

Grant only task-scoped access. Refuse skill installation scripts and automatic remote downloads. Review each SOURCE.md before enabling a vendored skill. These are adaptations, not a complete upstream plugin installation.

Run the corresponding eval case before trusting a new skill. Compare with a baseline without it. Review repeated failures together and stage any skill revision as a diff. You approve promotion; the agent cannot change its own permissions or acceptance tests.
