# Run the suite

Give your runner a frozen harness/model revision and disposable environment. Ask it to materialize each fixture, keep gold hidden and collect command/write receipts. Set dollar and wall-time caps before launch.

Grant synthetic fixture access only. Refuse production credentials and writable hidden tests. Review the first run of each case yourself. Compare final reports with actual receipts and inspect scope violations.

Repeat each case at least three times. Add held-out real repository tasks after these pass. You decide promotion based on accepted quality, cost and safety, not the best run.
