# Apply the checklists

Give your agent the acceptance criteria, required commands and known baseline failures. Ask it to attach evidence for each applicable gate and explain each exception. Do not accept an unchecked required item as done.

Grant only the sandbox access needed for those checks. Refuse production credentials as a shortcut for missing fixtures. Compare the final diff with the agreed scope. Run the fake-test and verifier-tampering evals before trusting checklist completion. You approve exceptions; the agent cannot weaken a gate to clear it.
