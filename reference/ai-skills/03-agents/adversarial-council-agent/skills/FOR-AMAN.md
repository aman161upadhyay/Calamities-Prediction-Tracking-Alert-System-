# Select one council procedure

Ask for adversarial review when you need defects, pairwise judging when you compare alternatives, and a pre-mortem when you need a probe plan. Supply the artifact, brief, budget and approved evidence.

Grant read-only access first. Refuse publication, production mutation and privileged configuration changes. Run the corresponding reviewer eval before adopting a skill change. Keep planning, criticism, repair and verification in separate sessions when their independence matters.
