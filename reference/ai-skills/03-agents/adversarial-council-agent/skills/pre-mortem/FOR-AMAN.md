# Plan failure probes

Ask: “Assume this artifact failed during this use period. Propose concrete mechanisms and safe tests.” Supply user context, constraints and a budget.

Grant read-only evidence access. Refuse actual attacks until you approve their scope. Check that each hypothesis has a falsifier and a measurable outcome. Use eval 008 to test uncertainty discipline. Choose the probes, then hand them to an independent reviewer instead of treating vivid scenarios as proven risks.
