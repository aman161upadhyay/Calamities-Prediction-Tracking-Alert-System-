# Research rubric

Check entailment, not just citation presence.

| Criterion | PASS evidence | FAIL example |
|---|---|---|
| Claim support, hard | Each material claim has an attributable source passage that supports it. | A working URL supports a different denominator. |
| Integrity, hard | No invented paper, quote, metric or repository. | A plausible title has no verified source. |
| Currency, hard when material | Moving numbers have dates and version-sensitive claims match the brief. | Historical library behavior is presented as current. |
| Counterevidence, hard when material | Strong conflicting evidence is addressed with limits. | A recommendation omits a known restrictive license. |
| Decision utility, diagnostic | Conclusions distinguish evidence, interpretation and unknowns. | A source list never answers the user's choice. |

Record claim, exact location, source, passage, date and verdict. Mark inaccessible evidence UNKNOWN rather than inventing confirmation. Search snippets support only what is visible in them. Preserve disagreement rather than average incompatible measurements.
