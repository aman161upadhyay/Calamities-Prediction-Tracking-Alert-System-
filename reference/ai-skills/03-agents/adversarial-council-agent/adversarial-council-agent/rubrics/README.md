# Artifact rubrics

Use fixed criteria before reviewing candidates. Hard failures cannot be offset by diagnostic scores.

- `writing.md`: factual scope, audience and approved voice.
- `design.md`: rendered tasks, access and states.
- `code.md`: behavior, test sensitivity and honest verification.
- `research.md`: claim support, currency and counterevidence.
- `security-report.md`: authorized attack evidence and severity.
- `finding-quality.md`: located, reproducible, actionable findings.
- `FOR-AMAN.md`: selecting and calibrating criteria.
