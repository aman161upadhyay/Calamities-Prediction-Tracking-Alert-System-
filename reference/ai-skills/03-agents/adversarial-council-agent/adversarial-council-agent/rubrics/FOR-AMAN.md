# Freeze your acceptance criteria

Give the judge your brief and the matching rubric before it sees candidates. Add exact required viewports, test commands or factual sources where relevant. Supply accepted and rejected examples with explanations.

Grant only evidence-reading and approved verification access. Refuse rubric edits during scoring. Run case 008 and human-label a held-out sample before trusting verdicts. If the rubric misses a real requirement, version the change and rescore both baseline and candidate rather than changing only the losing result.
