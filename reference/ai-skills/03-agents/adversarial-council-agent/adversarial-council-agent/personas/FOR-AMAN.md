# Select the review lenses

Ask for the lens whose failure mode would hurt your user. Supply the brief, artifact revision and domain evidence. Use source verifier for factual recommendations, user advocate for interfaces and security attacker for privileged boundaries.

Give read-only evidence access and only approved sandbox probes. Refuse production mutation and arbitrary outbound traffic. Run the clean control and a matching seeded case in `../evals/` before relying on the role. Review false positives yourself. Assign a separate chairman after first reviews are complete; do not let a persuasive role replace a qualified human.
