# Council personas

Load one or more lenses with the shared system prompt; a persona does not grant tools or expertise.

- `skeptic.md`: assumptions and falsifiable counterexamples.
- `security-attacker.md`: authorized trust-boundary probes.
- `user-advocate.md`: task completion and recovery.
- `domain-expert.md`: technical invariants and version-specific evidence.
- `slop-detector.md`: brief-specific editing without authorship claims.
- `source-verifier.md`: entailment, provenance and dates.
- `chairman.md`: anonymous evidence aggregation and exit criteria.
- `FOR-AMAN.md`: selecting lenses and access.
