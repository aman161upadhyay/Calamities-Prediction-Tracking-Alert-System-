# Audit the handoff

Ask the reviewer to attach this checklist to its findings. Supply the frozen brief and evidence packet. Grant read-only access; refuse repair or push access in the critic session.

Check a reported reproduction yourself before approving repairs. Run the clean-control case in `../evals/` to detect pressure to invent issues. If a check is unverified, require an explicit limitation and assign a verifier rather than accepting a checked box.
