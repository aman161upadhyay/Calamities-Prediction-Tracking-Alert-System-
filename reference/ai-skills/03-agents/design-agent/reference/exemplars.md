# Interfaces worth studying

- [Twenty](https://github.com/twentyhq/twenty): record views, inline edits and filter workflows. The root is AGPL-3.0. A separate twenty-ui MIT claim needs pinned package verification before copying.
- [shadcn/ui](https://github.com/shadcn-ui/ui): editable component implementation and token composition. Use examples to inspect states, not as a complete page identity.
- [Radix Primitives](https://github.com/radix-ui/primitives): interaction contracts for dialogs and menus. Verify their composition in the final app.
- [Linear Method](https://linear.app/method): a product reference for focused work surfaces. The research fetch failed; no claim is made about current implementation or accessibility. Study with Aman in an authorized browser.
- [Attio table documentation](https://docs.attio.com/sdk/components/table): a product reference for object and view clarity. Research verification was search-only. Do not copy proprietary assets.

Twenty, shadcn and Radix are open-source implementation references. Linear and Attio are linked product references, not open-source code grants.
