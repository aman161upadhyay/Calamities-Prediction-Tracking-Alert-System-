# Preference is conditional

[Design Arena](https://designarena.ai/about) uses anonymous pairwise comparisons and Bradley-Terry ratings. That protocol estimates relative preference for the submitted tasks and raters. It does not measure conversion or WCAG compliance.

The [Builder Arena](https://www.designarena.ai/leaderboard/builder) snapshot on 2026-10-25 placed Replit Design Mode above the other listed builders. A builder includes orchestration and rendering tools, so its rank does not isolate a foundation model. Close estimates can overlap in uncertainty. The research could not fetch the foundation-model leaderboards reliably.

The community is self-selected. Its published scale claim does not establish the number or expertise of independent UI raters. No verified evidence here proves universal preference for dark, minimal, serif or rounded interfaces.

Use the method: freeze briefs, hide labels, randomize order, equalize content and viewports, and allow tie or unusable answers. Separate first-impression preference from interactive task results. Report failure rates rather than removing failed samples.

A preference win supports only this statement: these raters preferred this output on these briefs. Validate business outcomes separately.
