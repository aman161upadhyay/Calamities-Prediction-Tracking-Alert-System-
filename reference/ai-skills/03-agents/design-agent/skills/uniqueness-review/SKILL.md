# Review procedure

1. Read the accepted brief and `../../design-slop/catalogue.md`.
2. For palette, type, density, hero/artifact, grouping and motion, cite the specific user or subject fact that supports the choice.
3. Imagine an unrelated product with a different primary task. Identify choices that would survive unchanged without a reason.
4. Classify each as keep, revise or ask. Preserve familiar controls and explicitly requested aesthetics.
5. Revise only unsupported choices. Explain the connection between each change and the real task.
6. Return a choice-to-brief table, catalogue IDs, revised token/layout plan and remaining questions.

Do not claim that novelty improves usability. Do not replace purple gradients with a universal cream/serif template. Acceptance requires task fit and the accessibility floor, not a high count of unusual elements.
