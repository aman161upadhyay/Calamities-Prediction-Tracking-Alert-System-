# Theme specifications

- `arctic-frost.md`: cool palette and type.
- `botanical-garden.md`: plant-derived palette.
- `desert-rose.md`: warm muted palette.
- `forest-canopy.md`: forest palette.
- `golden-hour.md`: warm light palette.
- `midnight-galaxy.md`: dark palette.
- `modern-minimalist.md`: neutral palette.
- `ocean-depths.md`: maritime palette.
- `sunset-boulevard.md`: sunset palette.
- `tech-innovation.md`: technology-themed palette.
- `FOR-AMAN.md`: selection and checking.

Provenance and Apache-2.0 terms are in the parent folder.
