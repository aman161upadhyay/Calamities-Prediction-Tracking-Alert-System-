# Catalogue of unexamined defaults

These 68 tells are original synthesis from the sources in `../sources.md`, chiefly Anthropic, Vercel, W3C, Emil Kowalski and Rauno Freiberg. A tell becomes a finding only when it conflicts with the brief or a tested requirement. Intentional brand choices are allowed.

## Colour

| ID | Tell | Better alternative |
|---|---|---|
| C01 | Purple/indigo gradient on unrelated products | Tie palette to brand and contrast needs |
| C02 | Cream, serif and terracotta used as a universal cure | Choose from the actual subject and assets |
| C03 | Near-black and acid green regardless of setting | Choose theme from usage context |
| C04 | Pale secondary text | Measure foreground/background contrast |
| C05 | White text on a bright pastel action | Use a tested on-action token |
| C06 | Status uses colour alone | Add explicit status text or shape |
| C07 | Every metric uses positive green | Encode actual meaning and direction |

## Type

| ID | Tell | Better alternative |
|---|---|---|
| T01 | Inter selected without a role decision | Keep it when it fits; document roles and license |
| T02 | Tiny monospace labels everywhere | Reserve monospace for code or useful data alignment |
| T03 | Tracked capitals above every heading | Add labels only when they aid orientation |
| T04 | One arbitrary word has gradient emphasis | Use emphasis that follows meaning |
| T05 | Many near-identical sizes | Use a compact role-based scale |
| T06 | Edge-to-edge paragraphs | Constrain reading width and test leading |
| T07 | Centered multiline body copy | Left-align scan-heavy reading |
| T08 | Expressive font makes numbers hard to read | Use legible operational type and tabular figures |

## Layout

| ID | Tell | Better alternative |
|---|---|---|
| L01 | Same three-column feature grid everywhere | Sequence by decision and content length |
| L02 | Huge centered hero without evidence | Lead with the characteristic artifact or statement |
| L03 | Broadsheet rules for every subject | Use editorial structure only when reading order fits |
| L04 | Random gaps | Use shared spacing tokens with documented optical exceptions |
| L05 | Equal gaps inside and between groups | Use proximity to show relationships |
| L06 | Borders around every nested block | Group through space and surfaces first |
| L07 | Giant KPIs displace CRM records | Give the work area priority |

## Components

| ID | Tell | Better alternative |
|---|---|---|
| K01 | Identical rounded cards for all content | Choose lists, sections or cards by relationship |
| K02 | Glass panels over operational content | Use opaque surfaces with stable contrast |
| K03 | One radius for every component | Use a small hierarchy or native rules |
| K04 | Same shadow under every element | Reserve elevation for actual layers |
| K05 | Placeholder replaces field label | Use a persistent associated label |
| K06 | Success toast precedes persistence | Show pending until confirmed |
| K07 | Enabled button has no handler | Implement it or disclose unavailability |
| K08 | Hover-only actions | Provide keyboard and touch access |
| K09 | Invisible focus | Use visible focus that remains in view |
| K10 | Modal loses or traps focus incorrectly | Use a tested primitive with restoration |
| K11 | Ambiguous row click and checkbox action | Separate selection from record navigation |
| K12 | Back loses filters | Persist approved view state |
| K13 | Loading skeleton for every short action | Match feedback to actual latency |
| K14 | Destructive action beside routine save | Separate consequences and require proportional confirmation |

## Motion

| ID | Tell | Better alternative |
|---|---|---|
| M01 | Every section slides in on scroll | Keep content available; justify any reveal |
| M02 | Every card tilts on hover | Animate meaningful interactive affordances |
| M03 | Slow spring on frequent menus | Shorten or remove motion |
| M04 | Loop runs indefinitely without control | Honor reduced motion and provide pause when required |
| M05 | Scroll hijacking traps reading | Preserve native scrolling and a static fallback |
| M06 | Animation shifts layout | Reserve dimensions and prefer transform/opacity |
| M07 | Repeated input queues stale animation | Cancel or reverse from current state |

## Copy

| ID | Tell | Better alternative |
|---|---|---|
| W01 | Generic claim about AI power | Name the user's task and mechanism |
| W02 | Every button says Submit | Name the result, such as Save changes |
| W03 | Error has no recovery | Explain the failure and safe next action |
| W04 | Empty state is only an illustration | Explain absence and offer a useful action |
| W05 | Invented metrics or percentages | Require source, date and permission |
| W06 | Annual price omits annual charge | State effective monthly and actual charge |
| W07 | Auth blocks paste or password managers | Support accessible authentication |

## Imagery

| ID | Tell | Better alternative |
|---|---|---|
| P01 | Floating dashboard with unreadable labels | Show an approved workflow at readable scale |

## Icons

| ID | Tell | Better alternative |
|---|---|---|
| I01 | Emoji form the entire icon system | Use a coherent set with labels |
| I02 | Arrow appended to every CTA | Keep direction icons where they clarify meaning |
| I03 | Tiny unnamed icon action | Expand hit area and name the action |
| I04 | Arbitrary numbered markers | Number actual sequences only |

## Charts

| ID | Tell | Better alternative |
|---|---|---|
| D01 | Decorative chart lacks units and timeframe | Name metric, period and decision |
| D02 | Tooltip is the only source of values | Provide keyboard access and a data alternative |
| D03 | Table clips essential names and dates | Choose columns deliberately and expose full values |
| D04 | Synthetic trends look like live data | Require approved records and freshness labels |
| D05 | Pie chart chosen without a question | Choose comparison form from the analytical task |

## Mobile

| ID | Tell | Better alternative |
|---|---|---|
| N01 | Desktop sidebar squeezed onto a phone | Reprioritize task and navigation |
| N02 | iOS and Android use identical web controls | Respect platform back, sheets and target rules |
| N03 | All permissions requested at first launch | Ask in context with a reason |
| N04 | Keyboard covers primary action | Test keyboard-visible layout and safe areas |
| N05 | Fixed type breaks at large text | Support Dynamic Type or scalable sp |
