# Review defaults with evidence

Give the agent your brief, tokens and screenshots. Ask: “Identify choices that could belong to an unrelated product. Cite catalogue IDs and propose a task-specific replacement.”

Load only relevant categories after intake. Refuse a blanket color or font ban. If you intentionally request a gradient, keep it and test contrast. Grant screenshot inspection, not production changes. Compare the revised page blindly with the original, then complete the primary task. Keep the revision only when it improves your task or a measured accessibility requirement.
