# Mobile checks

- [ ] Platform and implementation framework are named.
- [ ] Back, tabs, sheets and system controls follow the platform.
- [ ] Safe areas and keyboard-visible layouts preserve actions.
- [ ] iOS Dynamic Type and Android scalable text work.
- [ ] Native interaction areas use platform guidance, not CSS-unit substitution.
- [ ] VoiceOver or TalkBack announces state and actions correctly.
- [ ] Large text, light/dark and high-contrast needs are tested.
- [ ] Permission requests occur in context and denial is recoverable.
- [ ] Offline drafts differ from server-confirmed records.
- [ ] Backgrounding preserves edits where required.
- [ ] Sync conflicts and stale availability have explicit recovery.
- [ ] Sensitive data is absent from public screenshots and analytics.
- [ ] Motion has a static alternative.
