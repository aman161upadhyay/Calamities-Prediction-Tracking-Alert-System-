# Landing-page checks

- [ ] Audience, product mechanism and next action are clear.
- [ ] The hero uses a meaningful artifact or approved demonstration.
- [ ] Proof has source, date and permission. Unsupported proof is omitted.
- [ ] Outcomes connect to actual capabilities.
- [ ] Order fits visitor intent rather than a fixed template.
- [ ] Main objections receive concrete answers.
- [ ] Pricing, trial friction and cancellation terms are explicit.
- [ ] The same primary CTA works on narrow screens.
- [ ] Forms and booking show recoverable failures.
- [ ] Accessibility floor and media rights pass.

Do not infer conversion impact from visual preference alone.
