# Inspect the review record

Ask for the final tree hash and retest evidence, not a transcript summary. Supply the approved brief and budget so you can compare actual scope and cost.

Grant log readers access only to sanitized records. Give an authorized verifier scoped access to private evidence when necessary. Refuse publication of raw secrets or private traces.

Check each closed major against its retest. Compare the round counts to the exit rule. Run schema validation on embedded findings and manually verify their evidence. If a log claims a command ran without a result reference, return it to the reviewer. Approve the push only after the final record matches the reviewed content.
