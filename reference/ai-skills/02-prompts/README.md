# Task prompt library

**Status (PRINCIPLES.md section 1):** authored, untested. These templates have not been through a recorded run yet; the first recorded runs are the agent smoke tests in `05-evals/results/`. Treat each prompt as a first version until a run record exists for it.

Use task contracts with explicit inputs and verification. These prompts are authored practice templates, not claims of measured effectiveness. Fictional businesses in examples must never become fabricated production evidence.

- `prompt-anatomy.md`: eight fields and six filled task examples.
- `prompt-engineering-principles.md`: evidence-ranked methods with failure conditions.
- `video-generation/`: shot structure, provider adapters and five complete prompts.
- `gif-and-micro-animation/`: GIF, Lottie, Rive and CSS/SVG tasks.
- `web-animation/`: Motion, GSAP and CSS feedback.
- `landing-pages/`: section order, copy rules and three complete briefs.
- `crm-and-dashboards/`: operational records, density and three complete briefs.
- `app-pages/`: pricing, onboarding, authentication, settings, tables and forms.
- `mobile-ui/`: native platform rules and three complete briefs.
- `ui-design-general/`: reference boards, typography and constraint-led design.
- `fabric-patterns/`: 25 selected patterns, provenance and required adaptations.
- `system-prompts-of-production-tools/`: link-only analysis, not copied leaked text.
- `sources.md`: authority, dates and limitations.
- `FOR-AMAN.md`: adaptation, permissions, run records and contribution policy.
