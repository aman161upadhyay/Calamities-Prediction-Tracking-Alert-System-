# Specify a state, not decoration

Give the agent the trigger, confirmed application state, dimensions, approved asset, tokens and byte budget. Ask for a storyboard and static fallback before authoring.

Grant local authoring and export tools. Approve paid image/video work separately. Refuse fake progress and success before persistence. Inspect the boundary, state truth and reduced-motion behavior on the delivery channel. Review measured output bytes with the agent before accepting an export.
