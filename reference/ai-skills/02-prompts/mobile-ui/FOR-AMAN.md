# Choose the platform first

Give the agent iOS or Android, implementation framework, supported versions and real task data. Supply physical context such as outdoor use or intermittent connectivity.

Grant local preview/device tests and redacted fixtures. Refuse real bookings, financial exports and paid OCR without approval. Ask for large-text, keyboard-visible and offline views. Test with VoiceOver or TalkBack and distinguish local save from server confirmation before accepting the flow.
