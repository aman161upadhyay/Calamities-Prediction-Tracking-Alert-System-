# emilkowalski/skills

Four selected MIT skills for motion review, mobile web behavior and content stress testing. Read SOURCE.md for the pin, security review and limits.

- [emil-design-eng](skills/emil-design-eng/SKILL.md): Gives a purpose-and-frequency gate for motion, with easing, origin and interruption examples.
  Load in design-agent for motion direction and coding-agent for component implementation; treat exact timing values as defaults.
- [review-animations](skills/review-animations/SKILL.md): Reviews a motion diff with located findings and a block-or-approve verdict. STANDARDS.md supplies its reference values.
  Load in design-agent for review and coding-agent before a motion change is accepted; verify findings rather than enforcing taste as a standard.
- [mobile-native](skills/mobile-native/SKILL.md): Diagnoses viewport, input zoom, hover, safe-area and touch problems in mobile web interfaces.
  Load in coding-agent for fixes and design-agent for device acceptance checks; this is not a React Native skill.
- [break-ui](skills/break-ui/SKILL.md): Tests plausible content extremes through the existing data boundary. CATALOG.md covers names, collections, media and environment.
  Load in coding-agent for dev-only fixtures and design-agent for layout review; report failures before changing the component.
